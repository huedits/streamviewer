# Version History

## v1.0.0 (Initial Release)
- Multi-platform stream support (Twitch, Kick, YouTube)
- Single, double, triple, and auto grid layouts
- Audio management system
- Duplicate stream detection
- Stream card animations
- Custom platform dropdown with SVG icons
- Responsive 16:9 aspect ratio
- Keyboard shortcuts
- Modular JavaScript architecture
- Version display in footer

---

### How to Update Version
1. Change `CONFIG.version` in `js/config.js`
2. Update this VERSION.md file with changes
3. The footer will automatically display the new version
